# Solution Lab · 풀이 작업실

시험지의 새 풀이와 선생님 손풀이의 보충설명을 만들고 검토하는 개인용 도구입니다.

## 시작

`시작.cmd`를 실행하면 이 PC의 앱을 열 수 있습니다. 실행 주소는 http://127.0.0.1:4317 입니다. 처음 구성할 때 필요한 의존성과 계산 환경은 이 작업에서 설치했습니다.

개발 중 변경한 화면은 앱 폴더에서 `pnpm build` 후 반영합니다. 실행은 `pnpm start`, 검사 명령은 `pnpm check`와 `pnpm test`입니다. API 키는 기존에 승인한 `.env.local`에서 읽으며 화면이나 기록 저장소로 보내지 않습니다.

## 작업 순서

1. 새 풀이 또는 손풀이 보강을 선택하고 문제 PDF나 JPG·PNG·WebP 사진을 올립니다. 보강에는 원래 손풀이도 함께 입력합니다.
2. 새 작업의 **추가 요청**에서 그래프와 식의 연결, 경우 나누기, 학생 눈높이 중 이번에 강조할 내용을 고르거나 직접 적습니다. 공통 기준은 **제작 기준**에서 읽을 수 있습니다.
3. 작업을 저장한 뒤 풀이 작성을 실행합니다. 작업에 저장한 추가 요청은 원본 자료 탭에서 확인합니다. 원본, 보충설명, 그래프와 확인할 부분을 비교합니다.
4. 풀이를 편집하면 넓은 화면에서 결과와 편집을 나란히 봅니다. 설명·수식과 그래프 제목·축·곡선 표시를 수정할 수 있습니다. 수식이 바뀌면 관련 그래프와 확인 메모를 다시 검토합니다.
5. PDF 디자인에서 본문 크기·여백·단계 배치를 고르고 **PDF 미리보기 갱신**으로 실제 출력 형태를 봅니다. 수정 저장과 검토 완료는 작업 기록에 남습니다.
6. PDF로 내려받아 원본과 보충설명을 대조합니다. 새 작업은 사용자가 확정한 완성본 양식을 기본으로 사용합니다. 문제와 손풀이가 함께 있는 단일 문항 이미지에서는 원본 아래에 **손풀이 참고** 박스를 이어 배치합니다. 긴 설명은 같은 크기를 유지한 채 다음 쪽으로 이어집니다. 직접 검토를 마친 결과만 검토 완료로 표시합니다.

## 디자인 자료실

PDF나 사진을 레퍼런스로 등록하고 따라갈 요소를 메모합니다. 파일을 분석하도록 선택하면 OpenAI가 관찰과 적용할 설정을 제안합니다. 검토한 뒤 저장한 설정은 풀이의 그래프나 PDF 편집에서 불러올 수 있습니다.

저장한 레퍼런스를 **새 작업 기본으로 지정**하면, 이후 만드는 작업이 그 레퍼런스의 글자 크기·여백·단계 배치와 그래프 강조색으로 시작합니다. 기본 레퍼런스를 변경하면 다음 새 작업부터 적용됩니다. 새 작업의 기본 조판은 완성본의 손풀이·참고 박스 형식입니다. 기존 작업의 명시적인 조판 설정은 유지됩니다.

[완성본 출력 기준](docs/finished-format.md)은 PDF 내보내기와 새 풀이 생성에 적용합니다.

## 기록 연결

앱은 인접한 `solution-lab-knowledge/manifest.json`에 열거된 자료를 읽고 해시·참조·단계 관계를 검사합니다. 잘못 저장된 갱신에는 마지막 정상 기록과 경고를 유지합니다. 원본 분석 폴더나 다른 채팅의 파일에는 쓰지 않습니다.

생성 결과에는 사용한 참고 기록 버전과 문항이 남습니다.

검토 완료 기록과 수정 이력은 보관하지만, 새로 생성한 보강본을 선생님의 원래 손글씨로 분류하지 않습니다. 현재 첫 버전은 검토 메모를 다음 작업에 자동 재사용하지 않으며, 이 기능은 평가 문항의 분리와 재사용 범위를 정한 뒤 연결합니다. 새 문제에서 선생님의 방식을 얼마나 잘 따르는지는 별도 검수가 필요합니다.

## 구성과 보관

- OpenAI API: 문제·손풀이 판독과 풀이 초안. 판독 불확실성은 결과에 표시합니다.
- SymPy: 허용된 식의 계산과 검산. 동치 여부가 불분명하면 미확정으로 남깁니다.
- 새 작업의 그래프와 그림은 `figure_recipe_v1` JSON으로 작성합니다. 로컬 렌더러가 이를 검증해 PNG로 그리고, 작업 화면과 PDF가 같은 렌더러를 사용합니다. 새 그래프는 흑백으로 조판하며 실선, 점선, 음영으로 구별합니다. PDF를 내보내면 레시피와 PNG의 SHA-256을 함께 기록합니다.
- 기존 작업에 저장된 그래프는 화면에서 JSXGraph로 표시하고, PDF에서는 해당 작업의 조판 방식으로 그립니다. 원본에 없는 정확한 함수를 개형에 임의로 부여하지 않습니다.
- SQLite: 이 PC의 작업·첨부·수정 이력·검토 완료 기록.

입력 파일은 합계 30MB·최대 4개입니다. 긴 시험지는 모델의 처리 한계에 따라 나누어 입력해야 할 수 있으며, 판독한 문항 수와 미확인 범위는 결과에서 확인합니다. PDF 내보내기는 한 번에 40문항·200단계까지입니다.

단일 문항에서 문제 파일과 손풀이 파일이 동일한 이미지임이 확인되면 원본을 한 번만 넣습니다. 바깥 빈 여백은 출력용 사본에서 줄이고, 업로드 원본과 위쪽의 문제 본문은 보존합니다. 전체 시험지 PDF나 여러 이미지의 문항별 대응을 추정해 잘라 붙이지 않습니다. 대응 정보가 없는 묶음은 원본을 별도로 보존한 뒤 문항별 해설을 제공합니다.

앱은 이 PC의 주소에만 열립니다. 첨부와 데이터는 `data/`, 계산 환경은 `python/.venv/`에 있으며 비공개 지식 기록 저장소의 자동 갱신 대상에는 포함하지 않습니다.
