# 해설 생성 금지 항목


## A. 표기 금지
1. **'선분'+overline 중복 금지**: `선분 $\overline{\mathrm{AB}}$` ✗ → `선분 $\mathrm{AB}$` ○. overline(`$\overline{\mathrm{AB}}$`)은 **길이**를 나타낼 때만. '중선', '선분 …의 길이'도 동일(`$\overline{PQ}$의 길이`=길이의 길이, 중복). ※가장 빈번(PQ·BC·AB·AO·CM·QR).
2. **경우·하위 구분에 원문자(①②③) 금지**: 선택지 번호와 충돌 → `(i),(ii)` 또는 `[경우 1],[경우 2]`. 원문자는 선택지에만.
3. **점 이름 글꼴 혼용 금지**: 이탤릭 `$B$ $F$ $P$ $H$` ✗ → 로만 `$\mathrm{B}$`로 본문·그림·key 통일.
4. **수를 일반 텍스트로 금지**: `-1`,`3` 평문 ✗(`-1`이 하이픈으로 보임) → `$-1$`,`$3$` math.
5. **닫힌구간 기호로 집합 쓰기 금지(공통수학2 함수)**: `치역 $[b-6,b-2]$`,`$Y=[0,6]$` ✗ → 조건제시법 `$\{y\mid 0\le y\le 6\}$`.

## B. 비교과 용어 금지 (→ 교과 용어/식 직접 표기)
6. **'임계값','반길이'(확통)** ✗ → `$P(|Z|\le1.96)=0.95$`, '신뢰구간 길이의 $\frac12$'.
7. **'차분몫'(미적1)** ✗ → `$\frac{f(x)-f(2)}{x-2}$` 또는 '평균변화율'.
8. **'정규화된 분모'(미적1)** ✗ → 식 직접 표기.
9. **'첫째 자연수'** ✗ → '1부터 n까지의 자연수'.
10. **'극값' 오용**(최대·최소 지칭) ✗ → '최댓값','최솟값'.

## C. 용어 통일·정확성
11. **용어 혼용 금지**: 신뢰도↔신뢰수준, 함수값↔**함숫값**(표준) — 본문·key·그림 한 용어 통일.
12. **'로그의 정의역'(부정확)** ✗ → '진수 조건에 의하여'.
13. **'그래프의 치역'** ✗ → '함수의 치역'.
14. **'위로/아래로 열린'** ✗ → '위로 볼록'/'아래로 볼록'.
15. **메타 표현 '원문'(학생용 풀이)** ✗ → '문제의 조건'.
16. **일대일함수 비표준 정의 문구** ✗ → '정의역의 서로 다른 두 원소 $x_1,x_2$에 대하여 $f(x_1)\ne f(x_2)$'.

## D. 모호성 금지
17. **지칭 순서·대상 명시**: '두 수열 공차의 차이'(순서 명시), '공통점에서 접하는 직선'(→'각 곡선에 접하는 두 직선'), '수선의 발'(어느 평면인지 명시).
18. **문자 재사용 금지**: 같은 문자($k$)를 다른 범위에 재정의 → 새 문자($m$).
